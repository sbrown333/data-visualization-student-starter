# Digital payments data

- `households_2023.csv` (Week 8): one row per household that answered the FDIC 2023 banking supplement (29,483), with the household weight in `weight`. Use `weight` for every rate. Blank means the question did not apply. See `src/assignments/week-08/README.md`.
- `banking_sample_10000.csv` (Weeks 4 to 7): my earlier sample. It leaves out people living alone, includes households that never answered, is unweighted, and has the mobile and online labels swapped. Kept only so the Week 8 page can compare it with the rebuilt file.
