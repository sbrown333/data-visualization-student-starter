# Digital payments data

- `households_2023.csv` (Week 8): one row per household that answered the FDIC 2023 banking supplement (29,483), 29 columns, with the household weight in `weight`. Use `weight` for every rate. Blank means the question did not apply.
- `banking_sample_10000.csv` (Weeks 2 to 7): the earlier 10,000-household sample.

Source: FDIC National Survey of Unbanked and Underbanked Households, 2023. See `src/assignments/week-08/README.md`.
