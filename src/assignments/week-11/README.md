Week 11: The Dashboard

One page, one set of filters. Five menus (income, age, education, employment, home ownership) plus clicking states on the map filter every panel at once: summary tiles, the state map, dot plots by group, and a heatmap of how banked households reach their account. Clicking a row in a dot plot or an age in the heatmap sets that filter too.

Data: rebuilt, weighted FDIC 2023 household file (public/data/digital-payments/households_2023.csv) and public/data/geo/us-states.json. Rates use the FDIC household weight; ranges are approximate 95% Wilson ranges; groups with fewer than 30 surveyed households are marked as too few.
